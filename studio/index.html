Gallery Studio

Add photographs to your gallery. In this browser, each photo is resized on its long edge, cleared of location and camera data, stamped with your copyright, and optionally watermarked. HDR photos keep their HDR. Only those copies are published; your originals never leave this device.

01Sign in

How to get one
  1. Open GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it “Gallery Studio”. Leave Resource owner as WtSg, and pick an expiration (for example, one year).
  3. Under Repository access, choose Only select repositories and select WtSg/WtSg.github.io. (“Public repositories” is read-only and won’t work.)
  4. Under Permissions, click Add permissions (or open Repository permissions), choose Contents, and set it to Read and write.
  5. Generate the token, copy it, and use it as the password. GitHub shows it only once. To fix an existing token, open it on the same page and click Edit; the token text stays the same.

Size and quality

Larger, higher-quality copies look sharper on big screens but are bigger files and easier to reuse. 2000 px at quality 86 is a good balance.

Copyright and details

Read from each JPEG, HEIC or AVIF before it is stripped. For the place, the photo's location, rounded to about a kilometre, is looked up on OpenStreetMap to find the town; you can change it before publishing. The location itself is always removed from the file and never published.
