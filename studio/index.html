Gallery Studio

Add photographs to your gallery. In this browser, each photo is resized to 2000 px on its long edge, cleared of location and camera data, stamped with your copyright, and optionally watermarked. Only those copies are published; your originals never leave this device.

1. Connect to GitHub

Paste a GitHub access token that can edit the WtSg.github.io repository. You only do this once per device.

How to create the token
  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Name it “Gallery Studio” and pick an expiration (for example, one year).
  3. Under Repository access, choose Only select repositories and select WtSg/WtSg.github.io.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else as is.
  5. Generate the token, copy it, and paste it below. GitHub shows it only once.
